# ax-trend

> AI/AX 트렌드 다이제스트 — GitHub 이슈로 발행·아카이브되는 한국어 AI 뉴스 스트림.

이 레포의 **이슈 목록 자체가 다이제스트**입니다. 새로운 AI/AX 소식이 올라오면 이슈 하나로 발행되고,
오래된 이슈까지 포함해 전체가 검색 가능한 아카이브가 됩니다.

## 구성

```
ax-trend/
├── engine/                  # 발행 엔진 — 어떤 에이전트에서든 실행 가능한 파이프라인
│   ├── README.md            # 엔진 소개·아키텍처·멀티 에이전트 중복 방지 구조
│   ├── RUNBOOK.md           # 에이전트용 실행 절차
│   ├── config.example.yaml  # 설정 템플릿
│   ├── LESSONS.md           # 실운영 실패 교훈
│   ├── prompts/             # 선별 채점·이벤트 군집·이슈 형식 프롬프트
│   └── scripts/             # fingerprint.sh (발행 전 중복 대조)
└── .github/
    ├── workflows/           # 자동화
    └── ISSUE_TEMPLATE/      # 이슈 템플릿
```

**[engine/](./engine/)** 은 특정 에이전트에 종속되지 않은 프롬프트 기반 발행 파이프라인입니다.
수집 → 채점(독립 2회, 소스 등급별 임계값) → 군집(이벤트 단위 중복 판정) → 발행 → 보고.
AIHOT의 아키텍처를 차용하되 한국어·한국 시간대 기준으로 설계됐고,
여러 에이전트가 동시에 이슈를 올려도 중복이 안 생기는 3중 장치(핑거프린트 대조 → 군집 판정 → 레인 분담 + Action 사후 정리)를 갖추고 있습니다.

## 자동화 (GitHub Actions)

| 워크플로우 | 트리거 | 동작 |
|---|---|---|
| `deduplicate-issues` | 이슈 생성 시 · 매월 1일 02:00 UTC · 수동 | 제목을 정규화(특수문자 제거·소문자화)해 클러스터링하고, 같은 클러스터에서는 본문 품질이 가장 좋은 이슈 1개만 남김. 나머지는 `duplicated` 라벨 + 원본 이슈 링크 코멘트 후 종료 |
| `unicode-fixer-ci` | (CI) | 유니코드 정규화 |

## 이슈 작성 규칙

- **제목**: 한국어. 핵심 엔터티 + 사건 + 날짜/출처. 예: `Mistral, 신규 AI 모델 발표 예고 — 중국 모델 대비 사이버 분야 우위 주장 (10/6, Reuters)`
- **본문**: 300~450단어 다이제스트 — 핵심 사실 5~8불릿(수치 원문 그대로) + 배경·맥락 + 미확인 사항/쟁점 + 실무 함의 + 원문 링크 1~3개. 과요약 금지, 원문에 없는 내용 창작 금지.
- **신선도**: 원문 `datePublished` 기준 48시간 이내만 발행. 검색 스니펫 날짜가 아닌 원문을 직접 확인.
- **중복**: 하나의 사건 = 하나의 이슈. 발행 전 `engine/scripts/fingerprint.sh`로 최근 이슈 핑거프린트 대조 후, 애매하면 발행하지 않음.
- **핑거프린트**: 본문 끝에 `<!-- ax-events: 토큰1,토큰2 -->` 삽입 (엔터티 단일 토큰 분해, 영문 소문자 + 한글 원형).
- **라벨**: 다이제스트 이슈에는 라벨을 붙이지 않음. 심층 분석 이슈는 `[분석]` 템플릿 사용 (`analysis` 라벨).

## 기여하기

1. `engine/config.example.yaml`을 복사해 `config.yaml` 작성 (레포·독자 정의·임계값·레인)
2. 에이전트에게 `engine/RUNBOOK.md`를 그대로 전달해 한 사이클 실행
3. 동시에 도는 에이전트와 레인이 겹치지 않게 `lanes` 분담
4. 잔여 중복은 `deduplicate-issues` Action이 자동 정리 — 걱정 말고 발행
